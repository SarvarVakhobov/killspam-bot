## Что это такое

Бот для модерации Telegram-сообществ — учебных IT-групп, обсуждения фильмов и других. Любой может добавить его в группу, выполнить `/enable` и сразу получить защиту. Бот **мультиарендный (multi-tenant)**: каждая группа может подключить свой ключ Google Gemini (**BYOK**), а оператор при желании задаёт один **общий ключ** для групп без собственного. Даже без ключей бесплатные проверки — локальное сканирование фото, описания профиля со ссылками 18+, замаскированные ссылки, загрузки приложений и массовые рассылки ссылок — продолжают защищать группу.

## 🎯 Что блокируется — а что нет

Бот реагирует **только на следующее**:

| Блокируется | Как обнаруживается | Действие |
|---|---|---|
| **Фейковые аккаунты 18+** | явно непристойное фото профиля (NudeNet, локально) · описание профиля со ссылкой рядом со словами 18+ | бан + удаление |
| | ИИ признаёт сообщение или описание профиля сексуальным контентом или ловушкой спам-бота | удаление + мут на 24 ч |
| **Опасные ссылки** | домен ссылки антивирусы VirusTotal считают вредоносным | бан + удаление |
| **Замаскированные ссылки** | в тексте ссылки виден один сайт, а открывается другой (`https://gov.uz/…` → `evil.cc`) | удаление + мут на 24 ч |
| **Загрузки приложений** | прикреплённый файл `.apk`/`.exe`, ссылка на него в сообщении или ссылка на приложение в описании профиля | удаление + мут на 24 ч |
| **Массовые рассылки ссылок** | одно и то же сообщение со ссылкой от 3+ аккаунтов за 2 минуты | все копии удаляются + мут на 24 ч каждому |

**Не блокируется:** реклама и объявления, собственный канал или ссылка-приглашение участника в описании профиля (`t.me/+…`), разговоры о крипте, оскорбления, флуд, обсуждение фильмов (включая возрастной рейтинг). Прежние версии мьютили людей за часть этого — эти правила удалены.

При **муте на 24 часа** участник остаётся в группе — читает, но не пишет, — и ограничение снимается само. Админы группы (и оператор при `OPERATOR_ALERTS=1`) получают уведомление с кнопками **Ban / Unmute**, так что ошибка исправляется одним нажатием.

## ✨ Возможности

- **Мультиарендность и самообслуживание** — добавьте бота, введите `/enable` в группе, и готово. Админы каждой группы получают её уведомления.
- **Обнаружение фейковых аккаунтов 18+** — фото профиля проверяются локально через NudeNet (без облачных запросов), сомнительные фото не вызывают действий. Описания профиля и сообщения оценивает ИИ-слой, настроенный помечать только сексуальный контент и ловушки спам-ботов.
- **Блокировка фишинга и мошеннических приложений** — замаскированные ссылки и загрузки приложений (файлы и ссылки `.apk`/`.exe`) ловятся бесплатно и без сетевых запросов. С ключом VirusTotal проверяется ещё и настоящий домен каждой ссылки (и его родительский домен), а отправитель ссылки, подтверждённой как вредоносная, банится. Отправляется только домен, результаты кэшируются, крупные платформы не проверяются вовсе.
- **Обнаружение массовых рассылок ссылок** — если несколько аккаунтов одновременно отправляют одно и то же сообщение со ссылкой, все копии удаляются, а каждый отправитель получает мут; админам приходит одно уведомление с кнопкой Unmute для каждого аккаунта. Сообщения без ссылок не учитываются, поэтому одинаковые приветствия безопасны.
- **Ключи Gemini и VirusTotal: свои или общие** — `/setkey` (Gemini) и `/setvtkey` (VirusTotal) сохраняют собственный ключ группы через одноразовую веб-форму: ключ проверяется и хранится в зашифрованном виде. Оператор может задать общие ключи для всех групп без своих (`/globalkey`, `/globalvtkey`); собственный ключ группы всегда в приоритете. У каждого ключа VirusTotal свой дневной лимит.
- **Переключатель ИИ для оператора** — `/ai` показывает все группы со статусом ИИ и включает или выключает ИИ сразу во всех группах или по одной. Группы, добавленные позже, следуют настройке по умолчанию.
- **Лента банов для оператора** — при `OPERATOR_ALERTS=1` каждый бан и мут во всех группах дублируется оператору в ЛС с названием группы, аккаунтом и причиной.
- **Проверка при вступлении и по первому сообщению** — профили проверяются и при вступлении, и при первом сообщении, так что вошедшие по ссылке в публичные группы тоже под контролем.
- **Инструменты для администраторов** — `/ban`, `/mute`, обучение ключевым словам, пометка аккаунтов и обратная связь по ошибкам классификации — всё прямо в Telegram.
- **Отчёты об использовании и активности** — `/tokens` показывает расход токенов Gemini и стоимость; `/stats` — список групп, работает ли в каждой ИИ на самом деле и сколько спама поймано; оператор получает утренний отчёт.
- **Чистота по умолчанию** — собственные уведомления бота и команды админов автоматически удаляются из группы через несколько секунд.

## 🧠 Как это работает

Каждое сообщение в защищённой группе проходит конвейер от дешёвых проверок к дорогим; первое срабатывание определяет результат:

1. **Проверка профиля (один раз на участника)** — при вступлении и при первом сообщении.
   - Явно непристойное фото (NudeNet) или описание профиля со ссылкой на контент 18+ → **бан + удаление**.
   - Описание профиля со ссылкой на файл приложения (`.apk`/`.exe`) → мут на 24 ч.
   - Иначе описание профиля уходит в ИИ-слой (шаг 4); вердикт 18+ → мут на 24 ч.
2. **Проверка ссылок** — сначала загрузки приложений и замаскированные ссылки (бесплатно → мут на 24 ч), затем репутация домена в VirusTotal с ключом группы, общим ключом оператора или ключом сервера (подтверждённая угроза → **бан**). Выполняется до ИИ, поэтому такое сообщение не тратит вызов Gemini.
3. **Уровень ключевых слов (бесплатно)** — только слова, которым админы группы обучили бота через `/teach`. Базовый список сам по себе ничего не блокирует.
4. **Уровень ИИ** — работает, если ИИ включён для группы (`/ai`) и есть ключ: собственный ключ группы, иначе общий ключ оператора. Gemini (по умолчанию `gemini-3.1-flash-lite`) оценивает только контент 18+. Частота запросов ограничена для контроля расходов.
5. **Детектор массовых рассылок ссылок** — одно и то же сообщение со ссылкой от 3+ аккаунтов за 2 минуты → все копии удаляются, каждый отправитель получает мут на 24 ч.

Всё изолировано по группам, и бот полностью молчит в группах, где не выполнена команда `/enable`.

**Конфиденциальность:** ключи Gemini и VirusTotal (групповые и общие) хранятся зашифрованными с помощью Fernet. Текст сообщений уходит в Google Gemini только там, где включён ИИ. Домены ссылок уходят в VirusTotal только при заданном ключе — само сообщение никогда. Тексты отчётов о спаме и данные об использовании удаляются через 90 дней.

## 🛠️ Установка и деплой

Бот работает как один воркер на long-polling плюс небольшой веб-эндпоинт для формы ввода ключа. Два способа развернуть:

- **Docker, любой сервер** — `docker compose up -d --build` запускает бота на Python 3.11 с собственным PostgreSQL. См. [deploy/README.md](deploy/README.md).
- **Railway** — см. [DEPLOY.md](DEPLOY.md).

### 1. Создайте бота
В Telegram напишите [@BotFather](https://t.me/BotFather): `/newbot`, затем **отключите режим приватности** (`/setprivacy` → Disable), чтобы бот мог читать сообщения в группах. Этот режим фиксируется для группы в момент добавления бота — если измените его позже, удалите бота из группы и добавьте снова.

### 2. Клонирование и установка
```bash
git clone https://github.com/SarvarVakhobov/killspam-bot.git
cd killspam-bot
pip install -r requirements.txt
```

### 3. Настройка окружения
Скопируйте `.env.example` в `.env` и заполните его:

| Переменная | Обязательно | Описание |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен Telegram-бота от @BotFather |
| `DATABASE_URL` | ✅ | Строка подключения к PostgreSQL |
| `ADMIN_TELEGRAM_IDS` | ✅ | ID операторов через запятую (системные уведомления, `/stats`, `/ai`, `/globalkey`) |
| `KEY_ENCRYPTION_SECRET` | ✅ | Ключ Fernet для шифрования сохранённых ключей Gemini. Создать: `python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"`. Не меняйте — иначе сохранённые ключи станут нечитаемыми |
| `BASE_URL` | ✅ | Адрес веб-эндпоинта бота (для ссылок `/setkey` и `/globalkey set`); должен открываться у того, кто переходит по ссылке |
| `GEMINI_MODEL` | ➖ | Модель Gemini для ИИ-модерации (по умолчанию `gemini-3.1-flash-lite`). Меняйте, когда Google выводит модель из оборота |
| `GEMINI_PRICE_IN` / `GEMINI_PRICE_OUT` | ➖ | $/1M токенов для оценки стоимости в `/tokens` (по умолчанию `0.30` / `2.50` — цены flash; укажите реальные цены вашей модели) |
| `OPERATOR_ALERTS` | ➖ | `1` — дублировать каждый бан/мут оператору в ЛС (по умолчанию `0`) |
| `VIRUSTOTAL_API_KEY` | ➖ | Резервный ключ VirusTotal для всего сервера: используется, если ни группа (`/setvtkey`), ни оператор (`/globalvtkey`) не задали ключ в боте (бесплатный ключ: virustotal.com → профиль → API key; 4 запроса в минуту и 500 в день на ключ). Проверки замаскированных ссылок и приложений работают и без ключа |
| `VT_MALICIOUS_THRESHOLD` | ➖ | Сколько антивирусов должны пометить домен, чтобы бот принял меры (по умолчанию `2`) |
| `REPORT_HOUR` | ➖ | Час утреннего отчёта (Asia/Tashkent) (по умолчанию `9`) |
| `MAX_GROUPS_PER_OWNER` | ➖ | Защита от злоупотреблений: макс. групп, которые не-оператор может включить через `/enable` (по умолчанию `20`) |

> ⚠️ Никогда не коммитьте настоящий `.env`. Он добавлен в gitignore — пусть так и остаётся.

### 4. Деплой
С Docker — по [deploy/README.md](deploy/README.md). На Railway создайте проект, добавьте плагин PostgreSQL, задайте переменные выше и запустите деплой. В обоих случаях команда запуска (см. `Procfile`):
```bash
python init_db.py && python -m spam_bot.main
```
`init_db.py` создаёт и мигрирует таблицы при каждом запуске. Локально можно выполнить эти же две команды.

### 5. Защита группы
1. Добавьте бота в группу и сделайте его **админом** с правами **Удаление сообщений** + **Блокировка пользователей**.
2. Выполните `/enable` в группе.
3. Для ИИ: либо выполните `/setkey` в группе (собственный ключ Gemini группы), либо как оператор отправьте боту в ЛС `/globalkey set`, чтобы задать общий ключ.
4. Для проверки ссылок через VirusTotal: выполните `/setvtkey` в группе или как оператор отправьте `/globalvtkey set`.
5. Как оператор отправьте боту `/ai` и выберите, в каких группах работает ИИ.

> ⚠️ ИИ **включён по умолчанию** во всех группах. Если сделать бота публичным с общим ключом, группы, добавленные посторонними, тоже будут расходовать этот ключ. Выключите значение по умолчанию в `/ai` и включайте ИИ только в выбранных группах.

## 💬 Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/enable` · `/disable` | Админы группы | Включение/выключение защиты группы |
| `/setkey` | Админы группы | Сохранение собственного ключа Gemini группы (приватная одноразовая ссылка) |
| `/setvtkey` | Админы группы | Сохранение собственного ключа VirusTotal группы (приватная одноразовая ссылка) |
| `/ban` · `/mute` | Админы группы | Модерация пользователя, на чьё сообщение дан ответ |
| `/tokens` | Админы / оператор | Расход токенов Gemini + стоимость (вчера / 7д / 30д) |
| `/stats` | Оператор (в ЛС) | Список групп со статусом ИИ + активность по спаму/банам |
| `/ai` | Оператор (в ЛС) | Включение/выключение ИИ во всех группах или по одной |
| `/globalkey` | Оператор (в ЛС) | Статус общего ключа; `set` — задать для групп без ключа, `off` — удалить |
| `/globalvtkey` | Оператор (в ЛС) | То же для общего ключа VirusTotal |
| `/help` · `/privacy` | Все | Руководство / политика данных |
